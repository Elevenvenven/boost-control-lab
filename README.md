# Boost Control Lab

STM32G431 Boost PI/PID 控制代码与交互调试练习台。

## 在线功能

- 搭建 PWM、ADC、反馈闭环和硬件保护链路
- 切换开环、P、PI、PID 控制器
- 调整 Kp、Ki、Kd、输入电压、目标电压和负载
- 注入负载突加与输入跌落
- 观察输出电压、占空比、误差、电流和故障锁存
- 在线浏览、复制和下载 STM32G431 控制源码

## 本地运行

```bash
npm install
npm run dev
```

## GitHub Pages

静态构建产物发布在 `gh-pages` 分支，站点源码保存在 `main` 分支。

## 安全说明

页面使用教学平均模型，不代替实际电路仿真。硬件上电前必须重新标定
ADC 分压、采样电阻、运放增益、PI 参数和保护阈值，并配置独立硬件过流保护。
